# Security reporting / Сообщения о безопасности

This policy covers potential security vulnerabilities in the public DotnetAuditLite repository.

Use **Report a vulnerability** on this repository's [Security advisories page](https://github.com/Dalkory/DotnetAuditLite/security/advisories). GitHub private vulnerability reporting is enabled. Do not disclose suspected vulnerabilities in public issues.

Describe the affected release or public commit, possible impact, and minimal reproduction steps using public code or synthetic data. Use placeholder paths. Do not attach complete Markdown/SARIF reports, client logs, private code, credentials, personal data or customer material. A private reporting channel is not permission to share client materials.

Use only systems and data you own or have explicit permission to test. Do not test third-party systems as part of a report.

For ordinary tool defects, use the [public tool-feedback form](https://github.com/Dalkory/DotnetAuditLite/issues/new?template=public-tool-feedback.yml) with public or synthetic inputs.

This reporting channel does not promise a bounty, a response or remediation deadline, or bespoke support.

## Кратко по-русски

О возможной уязвимости сообщайте через **Report a vulnerability** в разделе Security advisories этого репозитория, а не через публичный issue. Укажите публичную версию или commit, возможное влияние и минимальный синтетический пример. Не отправляйте реальные отчёты, клиентский код, логи, секреты и персональные данные. Проверяйте только свои системы или системы с конкретным разрешением. Срок ответа, исправления, вознаграждение и индивидуальная поддержка не обещаны.
